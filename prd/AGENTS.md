# 글침 개발 에이전트 지침

- 작업 시작 전에 **`GLCHIM_ANTIGRAVITY_SPEC.md` 전체를 읽고** 이를 기능/디자인 요구사항 기준으로 사용한다.
- `glchim_sentence_demo.html`은 과거의 문장별 카드 UI 참고용이며, 디자인과 코드의 복제 대상은 아니다.
- 반드시 실행 가능한 웹앱을 만들 것. 정적인 화면만 생성하지 말 것.
- **최우선 기능**: 분석하기 → 문장 카드 분리 → 진단만/AI 고쳐쓰기/고정 → 직접 편집 → 원하는 수정안만 적용 → 최종본 저장.
- 고정은 AI만 막고 **사용자 직접 수정은 막지 않는다**.
- API 키가 없어도 작동하는 Mock 데모를 필수로 구현한다. Mock 출력을 실제 AI라고 표시하지 않는다.
- 실제 AI 비밀 키는 프론트엔드와 Git에 노출하지 않는다.
- 기능 테스트와 README 실행 안내를 포함한다.
